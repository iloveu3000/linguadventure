# LinguaQuest - AI Language Learning

AI-powered language learning platform with gamification.

## Features
- AI-generated quizzes using Groq AI
- Multiple languages (Spanish, French, German, Japanese, Korean)
- XP and achievement system
- Beautiful glassmorphism UI
